# E-Commerce Analytics Dashboard

Інтерактивний аналітичний дашборд для дослідження продажів, прибутковості та ефективності дисконтної політики на основі датасету **Superstore Sales** (9,994 транзакції).

Проєкт розроблено в межах курсу «Інженерія даних» (Лабораторна робота №2) з акцентом на **Data Storytelling** та мультиатрибутивну візуалізацію даних.

![Dashboard Preview](report_images/dashboard_screenshot.png)

---

## 🚀 Основний функціонал

- **Ключові метрики (KPI)**: миттєвий розрахунок загального виторгу ($2.30M), чистого прибутку ($286K), рентабельності (12.47%), кількості замовлень та середнього чека (AOV).
- **Аналітичні візуалізації (4 виміри)**:
  1. **Динаміка у часі (Line & Area)** — сезонні коливання виручки та прибутку з піком у Q4 (Black Friday / різдвяний період).
  2. **Ієрархія асортименту (Treemap)** — структура продажів «Категорія → Підкатегорія» з кодуванням маржинальності від збиткових до високодохідних позицій.
  3. **Географічний аналіз (Choropleth Map)** — розподіл показників по штатах США з можливістю перемикання між виручкою та чистим прибутком.
  4. **Оцінка знижок (Multivariate Scatter Plot)** — виявлення критичного порогу рентабельності при дисконті понад 20%.
- **Динамічні фільтри**: вибірка за періодом дат, регіонами США та товарними категоріями з миттєвим перерахунком через reactive callbacks.

## 📦 Встановлення та запуск

```bash
# 1. Клонувати репозиторій або перейти у робочу директорію
cd Lab2

# 2. Створити та активувати віртуальне оточення
python3 -m venv venv
source venv/bin/activate  # для Linux/macOS
# venv\Scripts\activate   # для Windows

# 3. Встановити залежності
pip install -r requirements.txt

# 4. Запустити веб-сервер дашборду
python app.py
```

Після запуску відкрийте у браузері: **`http://localhost:8050/`**

## 💡 Ключові інсайти (Data Storytelling)

1. **Поріг руйнівної знижки**: при перевищенні порогу в **20%** знижки практично всі замовлення стають збитковими незалежно від категорії товару.
2. **Географічна аномалія**: штати Техас (-$25.7K) та Огайо (-$17.0K) генерують найбільші операційні збитки через завищений дисконт на місцях.
3. **Драйвер прибутковості**: категорія *Technology* забезпечує понад 50% загального чистого прибутку мережі (маржинальність 17.4%), тоді як підкатегорія *Tables* у меблях є хронічно збитковою (-8.6%).
