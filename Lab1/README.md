# E-Commerce Data Pipeline & BI Analytics

Реалізація аналітичного конвеєра обробки транзакційних даних (**Data Pipeline**) для збору, очищення, трансформації та агрегації інформації інтернет-магазину з формуванням готової вітрини даних (**Data Mart**) під потреби Business Intelligence (BI).

Проєкт виконано в межах курсу **«Методи та технології інженерії даних»** (ЛНУ ім. Івана Франка, факультет електроніки та комп'ютерних технологій, Лабораторна робота №1).

---

## 📌 Основна мета проєкту

Розробка та валідація надійного пайплайну обробки масиву сирих транзакцій (понад **286 000 записів**) інтернет-магазину за 2020–2021 роки для отримання стратегічних бізнес-метрик і підтримки прийняття управлінських рішень.

### Ключові етапи конвеєра даних:
1. **Ingestion (Прийом даних)**: автоматизоване завантаження напівструктурованого CSV-файлу з урахуванням кодування `windows-1251` та нестандартного роздільника (`;`).
2. **Data Cleaning & Validation (Очищення)**: виявлення аномалій типів даних, уніфікація десяткових роздільників (заміна `,` на `.`) та приведення числових значень до формату `float64`.
3. **Transformation & Feature Engineering (Трансформація)**: приведення фінансових і часових показників для багатовимірного аналізу.
4. **Aggregation (Аналітика та агрегація)**: розрахунок фінансових KPI, групування за географією, товарними категоріями, часовими інтервалами та демографією клієнтів.
5. **Serving / Data Mart (Підготовка вітрини BI)**: генерація багатовимірної зведеної таблиці (`pivot_table`) як структурованої вітрини для інтеграції з BI-інструментами (Power BI, Tableau, Dash).
