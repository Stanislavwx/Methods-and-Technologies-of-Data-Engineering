# Exploratory Data Analysis (EDA) — Automobile Dataset

Повний цикл розвідувального аналізу даних (**Exploratory Data Analysis**) для дослідження технічних характеристик, ринкової вартості та факторів ціноутворення автомобілів на основі набору даних **Automobile Dataset** (205 спостережень, 26 ознак).

Проєкт виконано в межах курсу **«Методи та технології інженерії даних»** (ЛНУ ім. Івана Франка, факультет електроніки та комп'ютерних технологій, Лабораторна робота №3).

## 📌 Мета проєкту

Побудова системного конвеєра первинного та поглибленого аналізу даних (Data Understanding, Quality Audit, Univariate/Bivariate Analysis, Normality & Outlier Detection, Correlation Analysis) для формування рекомендацій щодо побудови подальшого **Data Engineering & Machine Learning Pipeline**.

## 🔍 Ключові інсайти та результати аналізу

1. **Якість даних та приховані пропуски**:
   - Ознака `normalized-losses` містить **20% пропусків** (41 значення). Потребує групової імпутації медіаною або KNN.
   - Цільова змінна `price` містить 4 пропуски (1.95%) — рекомендовано до видалення з вибірки для ML-моделювання.
2. **Розподіли та нормальність**:
   - За тестом Шапіро–Вілка для всіх 16 числових ознак отримано **$p < 0.05$**, що свідчить про статистично значуще відхилення від кривої Гаусса.
   - Ознаки `price` (skew: +1.81), `engine-size` (skew: +1.95), `horsepower` (skew: +1.39) мають виражену правосторонню асиметрію та довгі важкі праві хвости (Heavy Right Tails).
   - Лише `height` (skew: +0.06) та `length` (skew: +0.16) близькі до симетричних форм.
3. **Природа викидів**:
   - Найбільша частка викидів у `compression-ratio` (13.66%, 28 авто) обумовлена конструктивною особливістю дизельних двигунів (ступінь стиснення 21–23 проти 8–10 у бензинових), а не помилками даних.
   - Викиди за ознакою `price` (6.97%, 14 авто) відповідають реальним флагманським авто преміум-сегменту (Porsche, Mercedes-Benz, BMW, Jaguar).
4. **Кореляційні зв'язки**:
   - **Найсильніші додатні**: `city-mpg` & `highway-mpg` ($r = 0.9713$), `length` & `curb-weight` ($r = 0.8777$), `engine-size` & `price` ($r = 0.8723$).
   - **Найсильніші від'ємні**: `horsepower` & `city-mpg` ($r = -0.8036$), `curb-weight` & `highway-mpg` ($r = -0.7975$).
5. **Нелінійні закономірності**:
   - Залежність витрати пального (`highway-mpg`) від спорядженої маси має вигляд гіперболи $y \sim 1/x$.
   - Чітка сегментація за типом приводу: передньопривідні авто (`fwd`) зосереджені в зоні економічних авто до $12,000, тоді як задньопривідні (`rwd`) домінують у сегменті потужних і дорогих авто (середня ціна $19,758 проти $9,245 у fwd).
